# Math CLI

A simple command-line interface (CLI) tool for performing math operations.

## Usage

To use the tool, run the `main.py` script with the desired command and arguments.

### Add

To add two numbers, use the `add` command:

```bash
python math_cli/main.py add <n1> <n2>
```

Example:
```bash
python math_cli/main.py add 2 3
# 5.0
```
